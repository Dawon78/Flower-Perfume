꽃:향 (花香)

사계절의 꽃으로 나만의 향수를 직접 조합하는 JSP 기반 커스텀 향수 쇼핑몰입니다. (대학 졸업 프로젝트)

기간: 2025.03.04 ~ 2025.05.16 (74일)
인원: 3명 (디자인 1, 개발 2)
기술: Java, JSP, JDBC, MySQL, Apache Tomcat 9, JavaScript, 카카오페이 API

주요 기능
커스텀 향수: 탑·미들·베이스 노트와 용량을 골라 향수를 만들고 바로 장바구니에 담기
카카오페이 결제: 결제 준비 → 승인 2단계 흐름, 결제 금액은 서버에서 직접 계산
사계 유형 테스트: 답변 점수로 계절 타입을 판정해 추천 상품 페이지로 연결
회원 기능, 장바구니, 주문 내역, 상품 추천, 관리자 페이지

담당 역할
카카오페이 결제 연동 및 서버 측 승인 처리
커스텀 향수 기능, 회원 기능, 상품·마이페이지·관리자 페이지 개발
사계 유형 테스트, 상품 추천 구현 / 주요 테이블 설계 / 일정 관리

프로젝트 이후 개선

수료 후 코드를 다시 점검하며 결제 흐름을 보완했습니다.

승인 확인 분기 수정: 성공 블록이 비어 있어 결제 실패 시에도 주문이 생성될 수 있던 문제를, 승인된 경우에만 저장하도록 수정
실패·취소 페이지 추가: 등록만 돼 있고 없던 실패·취소 페이지를 추가해 이전 화면으로 돌아가도록 처리
